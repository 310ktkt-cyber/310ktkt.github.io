# からだログ

iPhone縦表示を中心にした、体組成・カロリー記録用のPWAです。サーバーやアカウントは使わず、記録はすべてその端末・ブラウザの IndexedDB に保存されます。

## 起動方法

Node.js 20 以上を用意してから、次を実行します。

```bash
pnpm install
pnpm dev
```

表示されたURLをiPhone Safariで開きます。同じWi-Fi内の端末から開く場合は、開発PCのネットワークURLを利用してください。

テストと本番ビルドは次のコマンドです。

```bash
pnpm test
pnpm build
```

## iPhoneでホーム画面に追加する

1. Safariでアプリを開きます。
2. 共有ボタンをタップします。
3. **ホーム画面に追加** を選び、追加します。

追加後はスタンドアロン表示で起動できます。PWAのキャッシュはオフラインでアプリ本体を開くためのもので、データは端末内のIndexedDBに保存されます。SafariのWebサイトデータを削除すると、保存した記録も削除されるためご注意ください。

## CSVの想定形式

CSVは UTF-8（BOM付き可）・ダブルクォート付きの体組成計エクスポートを想定しています。必須ヘッダーは以下です。

- `測定日`（例: `2026/07/10 06:19`）
- `タイムゾーン`
- `体重(kg)` / `体脂肪(%)` / `体脂肪量(kg)` / `内臓脂肪レベル`
- `基礎代謝(kcal)` / `骨格筋(%)` / `骨格筋量(kg)` / `皮下脂肪率(%)`

測定日は `Asia/Tokyo` の日付（`YYYY-MM-DD`）として扱います。同じ日に複数の測定値がある場合は、最も遅い時刻の行を採用します。再インポートはCSV側の体組成を更新し、すでに入力済みの摂取・アクティブ消費カロリーは保持します。

消費カロリーは「基礎代謝 + アクティブ消費カロリー」で計算します。どちらかがない日はグラフを欠損として扱い、作り上げた値は表示しません。
